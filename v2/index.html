    Chapter 03/Owner/Aug – Sep 2026

    Sanctum. One pane for every AI agent.

    Agent observability and accuracy platform: what each agent did, per-step latency, tool calls, context growth, where it failed, and accuracy against SME and user feedback. Went from a prototype to three concurrent deployments and a passed formal design review in four weeks.

    • Manifest contract. Any agent onboards with one YAML file and one Helm line, zero platform code. Replaced 5 agent-specific route families with a single trace API of 16 endpoints.
    • Normaliser unifying 3 agent data shapes (JSONL blobs, append-only event rows, relational logs), byte-identical across 26,843 real events; injection-shaped identifiers rejected at load.
    • Agent score card with accuracy over time: Shuri 80.3% over 2,129 SME judgements, Sentinel chat 86.4% over 686 votes.
    • Two-tier performance layer: response cache with pre-warm, per-run metrics ledger, strictly read-only agent databases with tight connect and statement timeouts.
    • Self-onboarding kit: a Copilot skill, read-only DB introspector and three validation gates; plus an experimental LLM onboarding agent (~3.4K lines) with nonce-gated human approval and secret redaction.
    • Found through Sanctum: an agent under-reporting tool calls, a 14 MB payload breaking drill-downs, a Postgres NFS hang with 401 queued connections, and a copy-paste error in the leadership ground truth.
    • Pitched to senior leadership; led the design review and demo. Most code written by AI agents under my direction as architect, spec author, reviewer and deployer.

    Chapter 08/Led experiment arms, co-led program/Aug 25 – Sep 16, 2026

    A self-learning root-cause agent, measured properly.

    Agent that root-causes Concorde bugs and writes reusable knowledge after each run. My job was the experiments and the measurement rigor behind them.

    • Built a 95-bug corpus with per-bug RCAs and 6 source-grounded domain skills; pulled a 1,459-bug expansion set.
    • 17+ isolated Helm experiment arms (skills, RAG, SFT, reflector variants, held-out, retrieval), about 690 runs by day three.
    • Found 13 preloaded skills eating ~90% of context; trimmed 87% (168K → 22K chars).
    • Proved recall mathematically impossible under Jaccard (max 0.069 < 0.10) and switched to containment: 0/56 → 11/56, with offline replay of every routing decision.
    • Found 6 silent defects invalidating the memory results, including a store wiped between runs, a leak guard that never fired, and 29 of 37 wrong catalog entries.
    • Measurement rigor: judge SD 2.5 vs agent SD 27.2, minimum-detectable-effect analysis, a malformed-output detector at 100% precision over 335 runs that exposed a fake "+3.7" gain, a Simpson's paradox correction, and a frozen-KB control that disproved a claimed "learning decay".
    • Fine-tuned model eval solved 0 of 21 held-out bugs, which drove the pivot to RCA-only. Built a 159-bug benchmark with frozen, cited ground truth and a 1,249-line dependency-free bounded-memory engine reproducing the paper's numbers.

    Chapter 09/Led research → build → eval/Jul 15 – Aug 14, 2026

    Shuri "forever agent": an honest negative result.

    Can an alert-triage agent keep learning from its own episodes? I built the reflector and memory, ran the evaluation, and reported that at scale it did not help.

    • Architecture evaluation for the team lead and six iterations of the experiment plan; reflector pipeline (reduce, synthesize, decide, reconcile, log) with shadow tables and an isolated sandbox.
    • 18 learned rules from 480 episodes (10 deterministic at 100% purity), wave rollback, net-positive auto-disable, and Brier calibration that exposed a 103× SOFTWARE → TEST blind spot.
    • Retrieval-first memory: 668 runs into 488 episodes, 1536-d pgvector kNN gated by cosine ≥ 0.85.
    • Caught leakage behind a reported 62.9% and reported an honest ~0 lift; net result at scale was −24 over 272.
    • Root-caused "LLM timeouts" to a corporate proxy on internal H200 traffic: 200 OK in about a second afterwards.
    • Theory write-up: Bayes error 0.10 – 0.21, embedding holds 71% of label entropy. Alert taxonomy over 3,813 alerts and 2,243 systems.
    • Blind LLM triage eval: 10 closed bugs at pre-fix checkout, 10 parallel agents graded against the real fix. Layer 8/10, file 7/10, root cause 6/10, shippable patch 5/10, and model confidence inversely correlated with correctness, so confidence cannot gate auto-triage.
