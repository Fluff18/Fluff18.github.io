    Work · 01

    AI agents that do real engineering work.

    Agents only matter if they finish the job. These ran on real alerts, real crash dumps and real bugs.

    Alert investigation agent

    Storage arrays raise alerts that engineers triage by hand, and many are false alarms. Built an agent that investigates from the logs first, and took it to production with a full test suite and CI gate.

    Replays 289 real alerts in eval. Live on 1,000+ conversations.

    Root-cause agent with memory

    An agent that root-causes product bugs and writes reusable knowledge after every run. Led the experiment program: 17 isolated arms, 690 runs in three days.

    Fixed retrieval from 0 to 11 of 56 hard bugs solved.

    Team agent framework

    Part of the team whose investigation agent was chosen as the HPE Storage AI framework. Re-architected its specialist loop into a LangGraph subgraph with per-tool summarisation.

    Adopted as the team standard for new agents.

    Work · 02

    Developer platforms engineers use every day.

    Internal tooling is a product. It has users, outages, safety incidents and adoption numbers.

    MCP tool server

    One Model Context Protocol server for Bugzilla, GDB, code search and investigation tools, used by experts inside Copilot and by the team's agents. Led the P0 response when an agent posted without consent and shipped a human-approval gate on every write.

    6,300+ tool calls a week from about 150 engineers.

    Live debugging as a service

    Ran the service that opens GDB sessions on core dumps for humans and agents across five crash servers. Root-caused a desync that broke every agent command, and recovered a fleet-wide outage the same day.

    13,000 requests in the first 43 days.

    Access portal and no-code UI

    Approval-gated access to AI tools, built in about a day, so 200+ beta users could get in safely. Then a browser UI that lets engineers without a dev setup run the debugging agent with stop-and-steer.

    Unblocked the beta without a support queue.

    Work · 03

    Knowledge systems built from years of history.

    The best model is useless without the team's memory. I turned six years of debugging history into something agents can retrieve.

    Debugging knowledge base

    Mined 13,005 bugs with real debugging sessions and generated grounded analyses at scale with a deterministic prompt that stopped hallucinated commands. Owned generation and ingestion; merged 22 pull requests from nine contributors.

    5,600 new analyses in nine days. Vector store grew 5×.

    Customer-bug intelligence

    A daily pipeline that classifies customer and AI-tool bugs with an open-weight model, feeding an executive dashboard. Revived it after it silently died and fixed five root causes.

    Coverage from about 50% to 99%. 74 customer escapes traced to 62 root causes.

    Text-to-SQL over the warehouse

    Open-weight model querying Trino with self-correction so non-engineers can ask questions of the data.

    68% to 100% on strict test cases.

    Work · 04

    Measuring what agents actually do.

    If you can't score it, you shipped a demo. This is the work I'm proudest of.

    Agent observability platform

    Owner. One pane for every agent: what it did, per-step latency, tool calls, failures, and accuracy against expert feedback. Any agent onboards with one YAML file. Pitched it to senior leadership and led the design review.

    26,843 real events normalised. Scores agents at 80% accuracy over 2,129 expert judgements.

    Honest negative results

    Evaluated a self-learning "forever agent" for alert triage. Caught data leakage behind a reported 62.9% win, built a malformed-output detector that exposed a fake gain, and reported zero lift.

    Saved the team from shipping a result that wasn't real.

    Blind triage study

    Ten agents triaged ten closed bugs against the real fixes. Model confidence was inversely correlated with correctness.

    Confidence can't gate auto-triage. Human-in-the-loop stays.
